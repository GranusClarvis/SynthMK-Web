# SynthMK-Web

The website for [SynthMK](https://github.com/GranusClarvis/SynthMK) — open-source
synthetic monitoring for Checkmk. Static site (no build step), served via GitHub Pages.

- `index.html` — landing: features, vs-Robotmk comparison, quickstart, downloads
- `docs/` — install & usage documentation
- `assets/` — real screenshots captured from the SynthMK test lab
